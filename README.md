# DSA in Python

A structured collection of **Data Structures & Algorithms problems solved in Python**, focused on building strong problem-solving fundamentals and preparing for technical interviews.

The repository follows a **pattern-based approach** rather than random problem solving. The goal is not just to solve problems, but to understand the underlying technique so that it can be applied to unfamiliar problems.

---

## What This Repository Covers

The problems are organized around the major DSA patterns and concepts commonly tested in technical interviews:

* Arrays & Hashing
* Two Pointers
* Sliding Window
* Stack & Monotonic Stack
* Binary Search
* Linked Lists
* Trees & Binary Search Trees
* Heaps / Priority Queues
* Recursion & Backtracking
* Graphs
* Greedy Algorithms
* Intervals
* Dynamic Programming
* Tries
* Bit Manipulation
* Data Structure Design

---

## Goal

Solve **150 carefully selected problems** that collectively cover the core concepts required for DSA interviews.

The objective is to develop the ability to:

1. Identify the underlying pattern in a problem.
2. Develop a brute-force solution first.
3. Optimize the solution using an appropriate data structure or algorithm.
4. Analyze time and space complexity.
5. Handle edge cases.
6. Explain the solution clearly during an interview.
7. Solve variations of familiar problems without relying on memorized code.

> **The goal is pattern recognition, not problem-count inflation.**

# Complexity Reference

Every solution should include complexity analysis.

### Common Time Complexities

| Complexity   | Example                        |
| ------------ | ------------------------------ |
| `O(1)`       | Hash lookup / basic operations |
| `O(log n)`   | Binary Search                  |
| `O(n)`       | Array traversal                |
| `O(n log n)` | Efficient sorting              |
| `O(n²)`      | Nested loops                   |
| `O(2ⁿ)`      | Some backtracking problems     |
| `O(n!)`      | Permutation-based backtracking |

### Common Space Complexities

| Structure            | Typical complexity     |
| -------------------- | ---------------------- |
| Hash Map / Set       | `O(n)`                 |
| Stack                | `O(n)`                 |
| Queue                | `O(n)`                 |
| Recursion Stack      | `O(h)`                 |
| Graph adjacency list | `O(V + E)`             |
| DP table             | Depends on state space |

# How I Approach Each Problem

For every problem, I try to follow this process:

```text
Understand the problem
        ↓
Identify constraints
        ↓
Think of brute force
        ↓
Find the bottleneck
        ↓
Identify the pattern
        ↓
Choose the data structure
        ↓
Optimize
        ↓
Analyze complexity
        ↓
Test edge cases
        ↓
Implement in Python
        ↓
Explain the solution without code
```
