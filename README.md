# DSA in Python

A structured collection of **Data Structures & Algorithms problems solved in Python**, focused on building strong problem-solving fundamentals and preparing for technical interviews.

The repository follows a **pattern-based approach** rather than random problem solving. The goal is not just to solve problems, but to understand the underlying technique so that it can be applied to unfamiliar problems.

---

## What This Repository Covers

The problems are organized around the major DSA patterns and concepts commonly tested in technical interviews:

* Arrays & Hashing
* Two Pointers
* Sliding Window
* Stack & Monotonic Stack
* Binary Search
* Linked Lists
* Trees & Binary Search Trees
* Heaps / Priority Queues
* Recursion & Backtracking
* Graphs
* Greedy Algorithms
* Intervals
* Dynamic Programming
* Tries
* Bit Manipulation
* Data Structure Design
